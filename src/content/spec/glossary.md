# 용어 사전

브리핑에 나온 용어를 모아 둔 페이지입니다. 새 글이 올라오면 자동으로 갱신됩니다.

### FinCEN

미국 재무부 산하에서 금융범죄 관련 정보를 수집·분석하는 기관입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### LLMJacking

공격자가 탈취한 클라우드 계정이나 API 키로 AI 모델과 GPU 자원을 몰래 사용하는 행위입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### N-day 취약점

이미 공개됐지만 일부 시스템에 아직 패치되지 않은 취약점입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### TTP

공격자가 사용하는 전술·기술·절차를 뜻하며, 공격 패턴을 분석할 때 활용합니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 감사 가능성

시스템이 무엇을 했는지 기록을 남겨 사후 검토할 수 있는 특성입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 권한 범위 준수

에이전트가 승인받은 파일·도구·데이터에만 접근하는 원칙입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 멀티모달

텍스트뿐 아니라 이미지·음성·영상 같은 여러 종류의 입력을 함께 처리하는 방식입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 무단 접근

공격자가 허가받지 않은 계정이나 시스템에 들어간 상태입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 반복 신뢰성

같은 문제와 변형 문제를 여러 번 풀어도 결과가 안정적으로 유지되는 성질입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 벤치마크

AI 시스템의 성능을 같은 문제 세트로 비교하는 평가 기준입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 복원력

장애나 침해가 발생해도 핵심 서비스를 유지하거나 빠르게 회복하는 능력입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 실소유자 정보

법인이나 기업을 실제로 소유하거나 통제하는 사람에 관한 정보입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 자율형 에이전트

사람의 매 단계 지시 없이 도구를 호출하고 여러 작업을 연속 수행하는 AI 시스템입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 재현성

같은 데이터와 절차를 사용했을 때 비슷한 결과를 다시 얻을 수 있는 성질입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)
