# 용어 사전

브리핑에 나온 용어를 모아 둔 페이지입니다. 새 글이 올라오면 자동으로 갱신됩니다.

### CSRF

사용자가 로그인한 상태를 악용해 원치 않는 요청을 보내게 만드는 공격입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### CVE

공개된 보안 취약점에 부여되는 고유 식별 번호입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### CVSS

취약점의 공격 조건과 영향도를 0점에서 10점으로 평가하는 점수 체계입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### KEV

CISA가 실제 공격에 사용된 것으로 확인한 취약점을 모아 둔 목록입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### Lean

수학 증명과 프로그램의 논리적 성질을 검사하는 정리 증명 시스템입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### Python 경로

Python이 모듈을 찾는 디렉터리 목록으로, 공격자 파일이 포함되면 코드 실행으로 이어질 수 있습니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### RCE

원격 공격자가 대상 시스템에서 임의의 명령이나 코드를 실행하는 취약점입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### WebForms

ASP.NET에서 사용하는 오래된 웹 애플리케이션 개발 방식입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 경로 순회

`../` 같은 경로 조작으로 허용된 디렉터리 밖의 파일에 접근하거나 쓰는 공격입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 공격 표면

공격자가 접근하거나 악용할 수 있는 시스템의 모든 기능과 경로입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 레거시 의존성

현재도 애플리케이션에서 사용되지만 유지보수나 보안 업데이트가 중단된 외부 구성요소입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 서버 측 처리

사용자의 컴퓨터가 아니라 API 제공자의 서버에서 파일 변환과 분할을 수행하는 구조입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 설치 파일

웹 애플리케이션을 처음 구성할 때 데이터베이스와 설정을 만드는 프로그램입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 양자 회로

양자 컴퓨터에서 알고리즘을 실행하기 위해 양자 게이트를 순서대로 배치한 설계입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 역직렬화

저장되거나 전송된 데이터를 프로그램 객체로 다시 변환하는 과정입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 콘텐츠 계층

문서의 텍스트·이미지·수식처럼 모델이 처리할 데이터 종류를 구분한 것입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 파일 슬라이싱

큰 파일 전체가 아니라 필요한 페이지나 데이터 구간만 잘라 모델에 제공하는 방식입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)

### 형식 검증

프로그램이나 수학적 주장이 정해진 논리 규칙을 만족하는지 기계적으로 증명하는 방법입니다.

등장: [11.26](/ai-security-brief/posts/brief-2026-11-26/)
